| **PAC** | Pace | Commits in the last year |
| **SHO** | Shooting | Stars earned across repos |
| **PAS** | Passing | Pull requests + followers |
| **DRI** | Dribbling | Language diversity |
| **DEF** | Defending | Reviews + issues |
